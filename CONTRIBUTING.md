# Contributing

Contributions to the corner-based face alignment and detection code are welcome.

## Before you start

- Open an issue before large changes to model architecture, training behavior, or exported formats.
- For bugs, include the input type, command, environment, checkpoint/model configuration, and error output. Do not upload private images or face data.
- Keep pull requests focused and describe any impact on bounding boxes, corner landmarks, inference, or export behavior.

## Development workflow

1. Fork the repository and create a branch for your change.
2. Make the change and update relevant documentation or examples.
3. Run the applicable checks available for the changed code. State exactly what you ran; the repository does not currently provide a single pinned environment.
4. Open a pull request with the purpose, implementation notes, validation, and any model/data requirements.

Do not commit trained weights, datasets, private images, or credentials.
